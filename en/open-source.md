Open source is a large part of my work. Below are the projects I created or maintain.

## [Selenide](http://selenide.org)

a library for writing concise and stable UI tests in Java

## [Selenide examples](https://github.com/selenide-examples)

examples of using Selenide to test applications built with different frameworks

## [Hangman](https://github.com/selenide-examples/hangman)

a reference web application demonstrating automated tests (both unit and UI), an in-memory database for tests and demo mode, LiquiBase for database migrations, etc.

## [pdf-test](https://github.com/java-testkit/pdf-test)

a library for testing PDF content

## [xls-test](https://github.com/java-testkit/xls-test)

a library for testing XLS content

## [Flying Saucer](https://github.com/flyingsaucerproject/flyingsaucer)

a Java library for rendering XHTML and CSS to PDF

## [LittleProxy](https://github.com/LittleProxy/LittleProxy)

a high-performance HTTP proxy written in Java on top of Netty

## [Datafaker](https://github.com/datafaker-net/datafaker)

a Java library for generating fake data for tests

## [RePlay](https://github.com/replay-framework/replay)

a fork of the Play 1 web framework
