Опен-сорс — значительная часть моей работы. Ниже проекты, которые я создал или поддерживаю.

## [Selenide](http://selenide.org)

библиотека для стабильных и лаконичных UI тестов на Java

## [Selenide examples](https://github.com/selenide-examples)

примеры использования Selenide с разными фреймворками

## [Виселица](https://github.com/selenide-examples/hangman)

эталонное веб-приложение с автоматическими тестами (юнит- и UI-тестами),
in-memory базой данных для тестов и демо-режима,
LiquiBase для миграций базы данных и т.д.

## [pdf-test](https://github.com/java-testkit/pdf-test)

библиотека для тестирования содержимого PDF файлов

## [xls-test](https://github.com/java-testkit/xls-test)

библиотека для тестирования содержимого XLS файлов

## [geo-ip](https://github.com/codeborne/geoip)

сервис для определения местоположения по IP-адресу

## [mobile-id](https://github.com/codeborne/mobileid)

Java-клиент для сервиса аутентификации Mobile-ID (Эстония, Литва).
